# ニュース用サムネイル素材

AIはオレンジ、CGは青、ESOは緑。`*-news.svg` と `*-tips.svg` は日付なしの共通文字画像。文字はアウトライン化してあり、外部フォント・スクリプトは不要。

単体記事向け汎用画像は `library.json` を参照。AIモデル・3D編集・地形制作・幻想ゲームの4種類。いずれもAI生成の概念イラストで、製品スクリーンショットやESO公式画像ではない。記事の thumbnailAlt と sourceNote でもその旨を示す。該当する権利確認済みの実画像がある場合は実画像を優先する。

`thumbnail` は assets/news/ 内のパス、`thumbnailAlt` は空でない代替文。画像は表示サイズに最適化したWebP。素材は再利用し、毎日生成し直さない。
